> **Smart India Hackathon 2026 · Problem Statement 26089**  
> *Cooperative Gig Services Platform for Household & Community Services*

A full-stack service marketplace designed around a cooperative model,
where workers can connect directly with customers while supporting
transparent earnings and worker welfare.

**Core idea:** reduce platform dependency and give workers greater
participation in the value generated by the marketplace.

### 🌟 Why This Project Matters

| Conventional Model | Proposed Cooperative Model |
|--------------------|----------------------------|
| Platform commission | **No worker-facing platform commission** |
| Worker gets a limited share | **Higher worker earnings share** |
| Limited worker welfare | **Dedicated welfare allocation** |
| Platform-owned | **Cooperative-owned** |

### 🛠️ Technical Architecture

**Frontend**

- 📱 **Flutter** — Cross-platform mobile application
- 🌐 **HTML / CSS / JavaScript** — Web Single Page Application

**Backend**

- ⚙️ **Spring Boot 3** — REST APIs and application logic
- 🔐 **Spring Security + JWT** — Authentication & authorization
- 🗄️ **MySQL 8** — Relational database
- 🧩 **JPA / Hibernate** — Data persistence

**AI / ML**

- 🧠 **Python FastAPI** — AI microservice
- 🤖 **Scikit-learn** — Machine learning
- 📈 **Random Forest Regressor** — Demand forecasting

**DevOps**

- 🐳 **Docker** — Containerization
- ☁️ **Render** — Cloud deployment
- 📦 **Maven** — Build & dependency management
- 🔀 **Git / GitHub** — Version control
